# Моя книжечка рецептов

Сайт с рецептами: пересчёт порций, граммы ↔ ложки, фото и заметки «Как получилось», печать на А4/А5, разбор рецепта с ИИ.
Адрес: **https://recipes.tutormate.site** (после выкладки). Открыт без пароля, поисковики его не показывают.

## Как устроено

| Папка / файл | Что это |
|---|---|
| `public/` | Сам сайт: страницы, стили, скрипты, иконки |
| `server/server.js` | Маленький сервер на Node 24: отдаёт сайт и хранит рецепты. Внешних библиотек нет |
| `tests/` | Автопроверки: `npm test` |
| `Dockerfile`, `docker-compose.yml` | Запуск на сервере в Docker |
| `deploy/nginx-recipes.conf` | Настройка nginx для адреса recipes.tutormate.site |

Данные на сервере лежат в `/opt/recipes/data`:
- `recipes.sqlite` — рецепты, записи, миниатюры фото, настройки;
- `photos/` — фото в полном размере;
- `trash/` — удалённые фото, хранятся 30 дней;
- `backups/` — копия базы раз в сутки, последние 14 дней.

Отдельно от TutorMate: свой контейнер `recipes`, свой порт `127.0.0.1:3200`, своя папка с данными. Обновление книжечки TutorMate не затрагивает.

Ключ для ИИ хранится только в браузере каждого устройства. На сервер он не попадает, потому что книжечка открыта без пароля.

## Запуск на компьютере

```bash
node server/server.js
```

Сайт откроется на http://localhost:3000, данные будут в папке `data/`.

## Выкладка на сервер (Hetzner, 95.217.133.58)

DNS: в Namecheap (Advanced DNS) для tutormate.site есть запись `A recipes → 95.217.133.58`.

Выкладка и обновление — один файл: двойной щелчок по `deploy\deploy.cmd` (или запуск в терминале).
Он берёт последний коммит, отправляет его на сервер в `/opt/recipes/app` и запускает `deploy/server-deploy.sh`:
1. папка для данных `/opt/recipes/data`;
2. сборка и запуск контейнера `recipes` (`127.0.0.1:3200`);
3. nginx для `recipes.tutormate.site` (только в первый раз);
4. https-сертификат Let's Encrypt (только в первый раз).

SSH один раз спросит пароль ключа (`tutormate-deploy-key`, пароль — в файле рядом с ключом).
Другой ключ можно указать так: `set RECIPES_KEY=путь\к\ключу` перед запуском.

Данные в `/opt/recipes/data` при обновлении не трогаются.

## Как пользоваться

- **Добавить рецепт:** «Новый рецепт» → вставить текст → «Разложить по полям». Программа понимает и цифры, и слова: «два яйца», «полстакана», «полторы ложки».
- **Сложный текст или фото страницы из книги:** «Разобрать с ИИ» или «Фото из книги». Нужен ключ Anthropic (console.anthropic.com), один разбор стоит 3–7 центов.
- **Порции:** «−» и «+», «×½», «×2», «×3».
- **Граммы и ложки:** переключатель над ингредиентами. Размер стакана и вес ложек меняются в Настройках.
- **Фото и заметки:** «Добавить запись» в разделе «Как получилось».
- **Печать:** значок принтера на рецепте или «Печать книжечки» на главном экране.
- **Иконка на телефоне:** iPhone — Safari → «Поделиться» → «На экран „Домой“»; Android — Chrome → ⋮ → «Установить приложение».
